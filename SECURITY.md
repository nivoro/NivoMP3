# Security Policy

## Supported Versions

Only the latest released version of Nivo MP3 is currently supported with security updates.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Nivo MP3, please do not publicly disclose it before it has been reviewed.

Please report security issues through the GitHub Security Advisories feature or by contacting the project maintainer privately.

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version
- Potential impact
- Any relevant screenshots, logs, or proof of concept

## Response

Security reports will be reviewed as soon as possible.

If the issue is confirmed, a fix will be developed and released when appropriate. Users may be notified through a GitHub release or security advisory.

## Scope

This policy applies to the official Nivo MP3 repository and officially distributed releases.

Third-party software, services, websites, or modified versions of Nivo MP3 are outside the scope of this policy.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing security details.

Thank you for helping keep Nivo MP3 secure.
